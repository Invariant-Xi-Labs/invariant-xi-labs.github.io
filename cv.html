§ 3   FINDINGS

Selected findings

MAR 2026Reported upstream

OPNsense 26.1.5 — three interacting DNS-stack bugs

Three independent defects in OPNsense’s Unbound integration, found by PHP source review and confirmed via packet capture, socket analysis, and config-generation tracing. Together they compound to total DNS failure. Three formal reports with reproduction, root cause, and code-diff fixes submitted 2026-03-27.

  • Python module loaded unconditionally. $module_config initialised with python regardless of DNSBL state, causing SERVFAIL in chroot with no active blocklist. Fix: guard on enabled blocklist entries.
  • chroot hardcoded to /var/unbound. The restricted filesystem lacks device nodes for outbound UDP; confirmed by tcpdump (zero outbound packets) and repeated forwarder timeouts.
  • Heredoc blank line. forward-addr directives emitted outside the forward-zone block and silently ignored — forwarders never configured despite correct GUI settings.
FEB 2026Workaround validated

TheHive 5 / MISP 2.4 — authorization-header incompatibility

Root-caused via packet capture and HTTP trace: TheHive sends Authorization: Bearer <key> per RFC 6750; MISP 2.4 expects the raw key and returns HTTP 403 behind a misleading “check your API key” message. Validated an Apache mod_headers rewrite that strips the prefix; proposed a configurable authScheme parameter upstream. Report TH-MISP-001.

APR 2026Lab evidence

OP-002 — live adversary emulation and telemetry-gap analysis

Caldera 5.x emulation of SMB lateral movement across a three-host AD domain; surfaced five detection gaps, two critical, which drove structural architecture changes.

  • GAP-001, beacon-masquerade survival. splunkd.exe executing inside the wazuh-agent.exe (SYSTEM) process tree generated no alert — a trusted parent gave unconditional child-execution cover.
  • GAP-002, Sysmon EID 1 / EID 11 dissociation. A PowerShell file-create was captured while its process-create was absent, making command-line arguments unrecoverable; root-caused to ProcessCreate rule ordering.
  • Measured 27-second MTTD across four correlated Wazuh alerts; promoted invariant INV-14 (a Domain-Admin action produces a correlated Windows Security event 4672 within 60 s) from Roadmap to Enforced.
JUL 2026Platform guarantee

Apple Intelligence agentic surface — compiler-enforced authentication floor

Verified that the Swift compiler enforces a build-time minimum authentication policy for schema-conforming App Intents (.requiresLocalDeviceAuthentication for sensitive intents such as .photos.deleteAssets) — a defensive property, reported as a platform guarantee, not a vulnerability. Reverse-engineered the Capture Data diagnostic binary (Ghidra, arm64): all nine gather* routines dispatch externally, relocating the attack surface to the dispatch boundary.

§ 4   ARCHITECTURE

Frameworks and architecture

OSIM v2.0Published

Adversarially-validated detection architecture

18 machine-verifiable invariants, a four-level detection-confidence framework, and a compounding adversary-cost model over a six-stage kill chain. Identified that Tier-0 access and DNS exfiltration carry zero dwell time because no network path exists — structural elimination over detection speed. Six deception assets placed at exact privilege boundaries, each a zero-false-positive event.

AEROSSpecified

Formally-specified research-lab architecture

A NIST-SP-style architecture for a single-operator lab, with topological containment stated as a machine-checkable invariant — negative reachability proven by parsing firewall, VLAN, and mirror-session configuration into a graph. Defines an assurance ledger whose downgrade operator automatically demotes any Enforced claim lacking a resolvable check and a recent passing result.

AEROS-0In progress

Capability-confined execution on seL4

A workload executor on the seL4 microkernel in which a component’s authority is exactly its capability set. The static confinement checker (Python) is built and running: it parses a Microkit system description into an influence graph and decides mediation and authority invariants before boot, and found two specification defects on first execution. Runtime demonstrator in progress.
